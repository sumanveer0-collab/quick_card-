# 🚀 Vistaprint-Style Editor - Quick Start Guide

## ⚡ Get Started in 5 Minutes

This guide will help you quickly understand and use the new Vistaprint-style business card editor.

---

## 🎯 What's New?

**Professional Floating Toolbar** - Click any text on canvas to see a comprehensive formatting toolbar appear above it, just like Vistaprint Studio.

**Key Features:**
- ✅ 20 professional fonts
- ✅ Font size control (8-96px)
- ✅ Bold, Italic, Underline
- ✅ Text alignment
- ✅ 32 color presets + custom
- ✅ Letter spacing, line height, opacity, rotation
- ✅ Layer management
- ✅ Lock, hide, duplicate, delete
- ✅ Two-way sync with sidebar fields

---

## 🎨 How to Use

### 1. Add Text to Canvas

**Option A: Use Sidebar Fields**
```
1. Go to "Text" tab in left sidebar
2. Type in any field (Company Name, Full Name, etc.)
3. Click the + button next to the field
4. Text appears on canvas with default styling
5. Field becomes "linked" (green indicator)
```

**Option B: Quick Text Styles**
```
1. Scroll down in Text tab
2. Click "Heading", "Subheading", "Body", or "Small"
3. Text appears on canvas instantly
```

**Option C: Custom Field**
```
1. Click "Add Custom Text Field" button
2. Type your custom text
3. Click + to add to canvas
```

### 2. Edit Text on Canvas

**Single Click**
```
1. Click any text element on canvas
2. Floating toolbar appears above text
3. Use toolbar buttons to format:
   - Change font
   - Adjust size
   - Apply bold/italic/underline
   - Change alignment
   - Pick color
   - And more...
```

**Double Click**
```
1. Double-click text element
2. Text becomes editable inline
3. Type to change text
4. Changes sync to sidebar automatically
5. Click outside or press Esc to finish
```

### 3. Format Text

**Change Font**
```
Click font dropdown → Select font → Done
```

**Change Size**
```
Click - or + buttons → Or select from dropdown
```

**Apply Style**
```
Click Bold, Italic, or Underline → Toggles on/off
```

**Change Alignment**
```
Click Left, Center, or Right → Applies instantly
```

**Change Color**
```
Click color button → Pick preset or custom → Done
```

**Advanced Options**
```
Click More Options (⋯) → Adjust sliders:
- Letter Spacing
- Line Height
- Opacity
- Rotation
```

### 4. Manage Layers

**Move Forward/Backward**
```
Click ↑ to bring forward
Click ↓ to send backward
```

**Move to Front/Back**
```
Click More Options (⋯) → "Bring to Front" or "Send to Back"
```

### 5. Quick Actions

**Lock/Unlock**
```
Click lock icon → Prevents editing/moving
```

**Show/Hide**
```
Click eye icon → Hides from canvas
```

**Duplicate**
```
Click copy icon (or Ctrl+D) → Creates copy
```

**Delete**
```
Click trash icon (or Delete key) → Removes element
```

## 🔄 Two-Way Sync

**Sidebar → Canvas**
```
Type in sidebar field → Canvas updates automatically
```

**Canvas → Sidebar**
```
Edit text on canvas → Sidebar field updates automatically
```

**This works for linked fields only** (fields with green "Linked" badge)

## 💡 Pro Tips

### Tip 1: Link Fields for Easy Editing
```
Always link sidebar fields to canvas elements for easy bulk editing.
You can update all instances by changing the sidebar field.
```

### Tip 2: Use Quick Text Styles
```
Start with quick text styles (Heading, Subheading, etc.)
Then customize on canvas with the floating toolbar.
```

### Tip 3: Duplicate for Consistency
```
Format one text element perfectly
Then duplicate it (Ctrl+D) for consistent styling
Just change the text content
```

### Tip 4: Lock Important Elements
```
Lock elements you don't want to accidentally move
Especially useful for logos and background text
```

### Tip 5: Use Layer Controls
```
Bring important text to front
Send background elements to back
Keeps your design organized
```

## 🐛 Troubleshooting

### Problem: Toolbar doesn't appear
**Solution**: Make sure you're clicking a text element, not an image or shape.

### Problem: Can't edit text
**Solution**: Element might be locked. Click lock icon in toolbar to unlock.

### Problem: Text not syncing to sidebar
**Solution**: Element might not be linked. Check for green "Linked" badge in sidebar.

### Problem: Toolbar is cut off
**Solution**: Zoom out or scroll canvas to see full toolbar.

### Problem: Can't move text
**Solution**: Element might be locked. Unlock it first.

### Problem: Changes not saving
**Solution**: Changes save automatically. If issues persist, try refreshing the page.
