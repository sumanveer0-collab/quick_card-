# 🚀 Business Card Designer - Quick Start Guide

## ⚡ Get Started in 5 Minutes

### 1️⃣ Access the Designer
Navigate to the business card designer:
```
http://localhost:3000/business-cards
```

### 2️⃣ Choose a Template
- Browse 10+ professional templates
- Filter by category (Corporate, Luxury, Modern, etc.)
- Use the search bar to find specific styles
- Click "Preview" to see details or "Customize" to start editing

### 3️⃣ Customize Your Card

#### Add Elements
**Left Sidebar → Elements Tab:**
- Click "Text" to add text
- Click "Rectangle" or "Circle" for shapes
- Click "QR Code" for QR codes

#### Edit Properties
**Right Sidebar → Properties Panel:**
- Select any element on canvas
- Adjust position (X, Y)
- Change size (Width, Height)
- Modify colors, fonts, opacity
- Rotate elements (0-360°)

#### Manage Layers
**Left Sidebar → Layers Tab:**
- View all elements
- Click to select
- Reorder layers

### 4️⃣ Switch Between Sides
Click the **"Front Side" / "Back Side"** button in the center toolbar to toggle between card sides.

### 5️⃣ Save Your Design
Click the **"Save"** button in the top toolbar. Your design is saved to MongoDB.

### 6️⃣ Export Your Card
1. Click **"Export"** button
2. Choose format: PNG, JPG, or PDF
3. Select quality and resolution
4. Pick which side(s) to export
5. Click **"Export"** to download

## 🛠 Common Tasks

### Adding Text
1. Left Sidebar → Elements Tab
2. Click "Text" button
3. Text appears on canvas
4. Double-click to edit content
5. Use Right Sidebar to style

### Changing Colors
1. Select element
2. Right Sidebar → Color picker
3. Click color swatch or enter hex code
4. Color updates in real-time

### Adjusting Layout
1. Drag elements to reposition
2. Use grid for alignment (toggle with Grid button)
3. Check safe area guides (blue dashed border)
4. Zoom in/out for precision

### Creating QR Codes
1. Add QR Code element
2. Select it
3. Right Sidebar → QR Data field
4. Enter URL or text
5. Customize colors

## 📤 Export Settings

### For Screen Use
- **Format**: PNG
- **Quality**: 80-90%
- **DPI**: 150

### For Professional Printing
- **Format**: PDF
- **Quality**: 100%
- **DPI**: 300 or 600
- **Include Bleed**: ✅ Yes

### For Social Media
- **Format**: JPG
- **Quality**: 85%
- **DPI**: 150

## 🎯 Pro Tips

### Design Tips
✅ Keep text within the safe area (blue guides)  
✅ Use high contrast for readability  
✅ Limit to 2-3 fonts maximum  
✅ Align elements using the grid  
✅ Test at actual size before printing  

### Performance Tips
✅ Limit elements to 20-30 per side  
✅ Use simple shapes over complex graphics  
✅ Optimize uploaded images  
✅ Save frequently  

### Print Tips
✅ Always export at 300 DPI minimum  
✅ Include bleed margins for PDF  
✅ Use CMYK-friendly colors  
✅ Test print on regular paper first

## 🔧 Troubleshooting

### Canvas Not Showing
- Refresh the page
- Check browser console for errors
- Ensure JavaScript is enabled

### Elements Not Dragging
- Click element to select first
- Check if element is locked
- Try zooming to 100%

### Export Not Working
- Check file size limits
- Try different format
- Ensure design is saved first

### Colors Look Different When Printed
- Use CMYK color mode
- Test print before bulk printing
- Adjust brightness/contrast

### Common Questions

**Q: Can I upload my own logo?**  
A: Yes! Use the Uploads tab in the left sidebar.

**Q: How do I make text bold?**  
A: Select text → Right Sidebar → Font Weight → Bold

**Q: Can I save multiple designs?**  
A: Yes! Each design is saved separately in your account.

**Q: What's the standard business card size?**  
A: 85mm × 55mm (3.5" × 2") - already configured!

**Q: Can I share my design with others?**  
A: Yes! Set `isPublic: true` when saving.
