This is where **ALL the magic happens!** 

### Left Sidebar - 8 Tabs:

#### 1️⃣ TEXT TAB
**Icon**: `T` (Type icon)

**Features**:
- Add text button
- Text fields panel
- Font selection
- Text formatting

**How to Use**:
```
1. Click Text icon (T) in left sidebar
2. Click "Add Text" button
3. Text appears on canvas
4. Double-click to edit
5. Use toolbar for formatting
```

---

#### 2️⃣ UPLOADS TAB

## 🎯 CANVAS CONTROLS (Center Area)

### Top Toolbar:
```
[← Back] [Change Template] [Change Orientation] [Text Editor]
```

### Zoom Controls (Bottom Right):
```
[-] [100%] [+] [Fit]
```

### Canvas Actions:
```
- Click element → Select
- Double-click text → Edit
- Drag → Move
- Drag corners → Resize
- Drag rotation handle → Rotate
- Right-click canvas → Background menu
- Ctrl+Scroll → Zoom
```

### Keyboard Shortcuts:
```
Ctrl+Z → Undo
Ctrl+Y → Redo
Ctrl+D → Duplicate
Delete → Delete element
Esc → Deselect
```

## 🎯 QUICK ACCESS GUIDE

### Want to Add Text?
```
Customize Page → Text Tab (T icon) → Add Text
```

### Want to Add Shapes?
```
Customize Page → Graphics Tab (▢ icon) → Shapes Tab → Click shape
```

### Want to Add Images?
```
Option 1: Customize Page → Graphics Tab → Images Tab → Click image
Option 2: Customize Page → Uploads Tab → Upload your own
```

### Want to Add Icons?
```
Customize Page → Graphics Tab → Icons Tab → Click icon
```

### Want to Add Illustrations?
```
Customize Page → Graphics Tab → Illustrations Tab → Click illustration
```

### Want to Change Background?
```
Option 1: Customize Page → Background Tab → Choose color/gradient
Option 2: Right-click canvas → Choose background
```

### Want to Use a Template?
```
Option 1: Templates Page → Click "Use Template"
Option 2: Customize Page → Templates Tab → Choose template
Option 3: Customize Page → "Change Template" button
```

### Want to Save Design?
```
Customize Page → Save button (top right) → Enter name → Save
```

### Want to Edit Saved Design?
```
My Designs Page → Click design card → Opens in editor
```

## 🎨 EDITING ELEMENTS ON CANVAS

### Text Elements:
```
1. Click to select
2. Double-click to edit inline
3. Use floating toolbar for:
   - Font family
   - Font size
   - Font weight
   - Alignment
   - Color
   - Background
4. Drag to move
5. Drag corners to resize
6. Drag rotation handle to rotate
```

### Graphic Elements (Shapes, Images, Icons, Illustrations):
```
1. Click to select
2. Graphic toolbar appears with:
   - Color picker (shapes, icons, illustrations)
   - Opacity slider
   - Rotation input
   - Size inputs (width/height)
   - Layer controls (forward/backward)
   - Duplicate button
   - Delete button
3. Drag to move
4. Drag corners to resize
5. Drag rotation handle to rotate
```
