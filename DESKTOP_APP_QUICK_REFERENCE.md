## ⌨️ Keyboard Shortcuts

### Essential
- `Ctrl+Z` - Undo
- `Ctrl+Y` - Redo
- `Ctrl+S` - Save
- `Ctrl+C` - Copy
- `Ctrl+V` - Paste
- `Ctrl+D` - Duplicate
- `Delete` - Delete element
- `Esc` - Deselect

### Canvas
- `Space+Drag` - Pan canvas
- `Ctrl+Wheel` - Zoom
- `Ctrl+0` - Fit to screen
- `Ctrl+1` - 100% zoom

### Text
- `Ctrl+B` - Bold
- `Ctrl+I` - Italic
- `Ctrl+U` - Underline

### Layers
- `Ctrl+]` - Bring forward
- `Ctrl+[` - Send backward
- `Ctrl+Shift+]` - Bring to front
- `Ctrl+Shift+[` - Send to back

## 📐 Canvas Specifications

### Business Card Sizes
- **Standard:** 3.5" × 2" (89mm × 51mm)
- **Square:** 2.5" × 2.5" (64mm × 64mm)
- **European:** 85mm × 55mm

### Resolution
- **Screen:** 72 DPI
- **Print:** 300 DPI
- **Bleed:** 3mm (0.125")

### Safe Area
- **Margin:** 3mm from edge
- **Text:** 5mm from edge

## 💡 Pro Tips

### Design Tips
- Use grid for alignment
- Lock background layer
- Group related elements
- Use brand kit colors
- Save as template

### Performance Tips
- Close unused designs
- Clear cache regularly
- Use lower resolution for editing
- Export at high resolution
- Enable auto-save

### Workflow Tips
- Use keyboard shortcuts
- Create brand kit first
- Duplicate for variations
- Use layers panel
- Name layers clearly

## 🐛 Troubleshooting

### App Won't Launch
- Check system requirements
- Restart computer
- Reinstall app
- Check antivirus

### Canvas Lag
- Reduce zoom level
- Close other apps
- Lower canvas quality
- Update graphics drivers

### Export Failed
- Check file permissions
- Free up disk space
- Try different format
- Reduce file size

### Auto-save Not Working
- Check internet connection
- Verify account status
- Clear app cache
- Contact support
