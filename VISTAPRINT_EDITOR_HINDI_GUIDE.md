# 🎨 QuickCard - Vistaprint Style Editor (हिंदी गाइड)

## ✅ यह Feature Already Implemented Hai!

आपके QuickCard app में **Vistaprint जैसा customize page** पहले से ही add है। अब आप:

✅ Canvas पर text को **click करके select** कर सकते हैं  
✅ Text को **drag करके move** कर सकते हैं  
✅ Text का **size change** कर सकते हैं  
✅ Text को **rotate** कर सकते हैं  
✅ **Floating toolbar** text के ऊपर automatically आता है  
✅ **20+ fonts**, colors, alignment, और बहुत कुछ

## 🚀 कैसे Use करें

### 1️⃣ Text Add Karna

**Method 1: Sidebar Fields से**
```
1. Left sidebar में "Text" tab पर click करें
2. किसी भी field में text type करें:
   - Company Name
   - Full Name
   - Job Title
   - Phone
   - Email
   - Website
   - Address
3. Field के बगल में + button click करें
4. Text canvas पर add हो जाएगा
5. Field "Linked" हो जाएगा (green badge)
```

**Method 2: Quick Text Styles से**
```
1. Sidebar में नीचे scroll करें
2. "Quick Add Text Styles" section में जाएं
3. Click करें:
   - Heading (36px, bold)
   - Subheading (24px, semi-bold)
   - Body (16px, normal)
   - Small (12px, normal)
4. Text तुरंत canvas पर add हो जाएगा
```

**Method 3: Custom Field से**
```
1. "Add Custom Text Field" button click करें
2. नया field बन जाएगा
3. अपना text type करें
4. + button click करें
5. Canvas पर add हो जाएगा
```

---

### 2️⃣ Text Select Karna

**Single Click:**
```
1. Canvas पर किसी भी text पर click करें
2. तुरंत दिखाई देगा:
   ✅ Blue selection border
   ✅ Floating toolbar (text के ऊपर)
   ✅ Resize handles (corners पर)
   ✅ Rotation handle (ऊपर)
```

**Visual Indicators:**
- **Hover**: हल्का blue ring
- **Selected**: मध्यम blue ring
- **Editing**: गहरा blue ring with shadow

---

### 3️⃣ Text Move Karna (Place Change)

**Method 1: Drag करके**
```
1. Text को select करें (click करें)
2. Text पर mouse रखें
3. Click करके hold करें
4. Drag करें जहां चाहें
5. Release करें
```

**Method 2: Arrow Keys से**
```
1. Text select करें
2. Arrow keys press करें:
   - ↑ = ऊपर move
   - ↓ = नीचे move
   - ← = बाएं move
   - → = दाएं move
3. Shift + Arrow = तेज़ी से move (10px)
```

**Smart Features:**
- ✅ Snap guidelines automatically दिखते हैं
- ✅ Alignment guides दूसरे elements के साथ
- ✅ Safe area warning अगर बाहर जाए
- ✅ Smooth dragging, no lag

---

### 4️⃣ Text Size Change Karna

**Method 1: Toolbar Buttons से**
```
1. Text select करें
2. Floating toolbar में:
   - [-] button = Size decrease (2px कम)
   - [+] button = Size increase (2px ज़्यादा)
   - या Size dropdown से exact size चुनें
3. Size तुरंत apply हो जाएगा
```

**Method 2: Resize Handles से**
```
1. Text select करें
2. Corner handles दिखेंगे (4 corners)
3. किसी भी corner को drag करें
4. Text box का size change होगा
5. Text automatically adjust होगा
```

**Available Sizes:**
- 8, 10, 12, 14, 16, 18, 20, 22, 24, 28, 32, 36, 40, 48, 56, 64, 72, 80, 96
- Minimum: 8px
- Maximum: 96px

---

### 5️⃣ Text Rotate Karna

**Method 1: Rotation Slider से**
```
1. Text select करें
2. Toolbar में More Options (⋯) button click करें
3. "Rotation" slider दिखेगा
4. Slider को drag करें (0° to 360°)
5. Real-time में text rotate होगा
```

**Method 2: Rotation Handle से**
```
1. Text select करें
2. Text के ऊपर rotation handle दिखेगा
3. Handle को click करके drag करें
4. Circular motion में घुमाएं
5. Angle display होगा
```

**Rotation Features:**
- ✅ 0° to 360° range
- ✅ Real-time preview
- ✅ Snap to angles (0°, 45°, 90°, etc.)
- ✅ Smooth rotation animation

### 6️⃣ Floating Toolbar Features

**Toolbar Position:**
- Text के ठीक ऊपर (60-70px)
- Horizontally centered
- Auto-repositions on zoom/pan
- Smooth fade-in animation

**Toolbar Buttons (बाएं से दाएं):**

**1. Font Family Dropdown**
```
- Current font दिखाता है
- Click करें dropdown के लिए
- 20 professional fonts:
  Arial, Helvetica, Times New Roman, Georgia, Verdana,
  Courier New, Impact, Comic Sans MS, Trebuchet MS,
  Palatino, Garamond, Bookman, Avant Garde, Optima,
  Futura, Roboto, Open Sans, Lato, Montserrat, Poppins
- हर font अपनी style में दिखता है
- Click करें apply करने के लिए
```

**2. Font Size Controls**
```
[-] button = Size decrease
[Size dropdown] = Exact size select
[+] button = Size increase
```

**3. Text Formatting**
```
[B] = Bold (Ctrl+B)
[I] = Italic (Ctrl+I)
[U] = Underline (Ctrl+U)
- Toggle on/off
- Active state blue background
```

**4. Text Alignment**
```
[≡] = Align Left
[≡] = Align Center
[≡] = Align Right
- Instant apply
- Active state highlighted
```

**5. Color Picker**
```
[Color button] = Current color preview
- Click करें dropdown के लिए
- 32 preset colors (8x4 grid)
- Custom color picker
- Instant apply
```

**6. Layer Controls**
```
[↑] = Bring Forward (एक layer ऊपर)
[↓] = Send Backward (एक layer नीचे)
```

**7. Quick Actions**
```
[🔒] = Lock/Unlock (editing prevent)
[👁] = Show/Hide (visibility toggle)
[📋] = Duplicate (Ctrl+D)
[🗑] = Delete (Delete key)
```

**8. More Options (⋯)**
```
Dropdown में:
- Letter Spacing slider (-5 to 20)
- Line Height slider (0.8 to 3.0)
- Opacity slider (0% to 100%)
- Rotation slider (0° to 360°)
- Bring to Front button
- Send to Back button
```

## 🐛 Common Problems & Solutions

### Problem 1: Toolbar नहीं दिख रहा
**Solution:**
- Check करें कि text element select है (blue border)
- Zoom out करें अगर toolbar screen के बाहर है
- Page refresh करें

### Problem 2: Text move नहीं हो रहा
**Solution:**
- Check करें कि text locked तो नहीं (🔒 icon)
- Unlock करें toolbar से
- फिर drag करें

### Problem 3: Size change नहीं हो रहा
**Solution:**
- Text select करें पहले
- Toolbar में +/- buttons use करें
- या resize handles drag करें

### Problem 4: Sidebar sync नहीं हो रहा
**Solution:**
- Check करें field linked है (green "Linked" badge)
- अगर नहीं है तो + button से add करें
- Linked fields ही sync होते हैं

### Problem 5: Text delete नहीं हो रहा
**Solution:**
- Text select करें
- Delete key press करें
- या toolbar में 🗑 button click करें
