## 🚀 HOW TO USE ALL FEATURES

### Quick Start Guide

1. **Start Designing**
   - Go to `/customize` page
   - Or choose a template from `/templates` page

2. **Add Content**
   - **Text**: Click Text tab → Add text → Edit inline
   - **Graphics**: Click Graphics tab → Choose Shapes/Images/Icons/Illustrations → Click to add
   - **Background**: Right-click canvas or use Background tab
   - **Templates**: Click Templates tab → Choose template

3. **Edit Elements**
   - Click to select
   - Drag to move
   - Drag corners to resize
   - Drag rotation handle to rotate
   - Use toolbar for colors, fonts, etc.

4. **Save & Export**
   - Click Save button
   - Name your design
   - Download or order prints
